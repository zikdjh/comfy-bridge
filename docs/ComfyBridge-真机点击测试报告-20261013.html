三、发现的问题（均为 P3，不阻断使用）

#问题证据 / 影响建议
1 dev.ps1 在本机直接执行时前端启动失败（环境） pnpm shim 存在但 node 不在系统 PATH（node 安装于 E:\node\version\v24.20.0）， pnpm dev 报 “'node' is not recognized”。需手动把 node 目录注入 PATH 后才能启动。 文档/脚本
2 启动期 Modal API 限流导致首检失败 VolumeListFiles rate limit exceeded，使节点在场索引、系统状态首检短暂失败；系统状态页已有留痕与建议，手动重试即恢复。 可加退避
3 antd 弃用告警（仅控制台） [antd: Modal] destroyOnClose is deprecated. Please use destroyOnHidden instead. 不影响功能。 择机替换

说明：开发模式下浏览器控制台偶现 net::ERR_ABORTED（events/stream、settings-sync、media 等）， 系 React StrictMode 双重挂载中止首个请求所致，生产构建不存在，非产品缺陷。
