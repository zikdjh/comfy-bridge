# ComfyBridge 第二轮完整测试计划

> 生成时间：2026-10-11。第一轮真机验收（版本对齐 + 节点同步 + LV-01..LV-06 修复）已闭环；
> 本计划是第二轮完整回归 + 性能压测的执行清单，按功能模块拆分测试项。

## 1. 测试范围与策略

| 层次 | 工具 | 范围 | 触发方式 |
|------|------|------|----------|
| 单元/集成 | pytest | 后端全量 369 用例 | `cd backend && pytest` |
| E2E（UI） | Playwright | 管理台 10 页渲染 + 核心链路 | `cd frontend && pnpm exec playwright test` |
| 真机冒烟 | pytest -m live | 真实本地 ComfyUI + 真实 Modal | `pytest -m live`（需 CB_LIVE_* 环境变量） |
| 性能 | httpx + Locust（视需要） | 管理面 API 吞吐/延迟、数据面代理吞吐、SQLite 写入 | 本计划第 4 节专项 |
| 兼容性矩阵 | pytest | 三版本 ComfyUI 协议夹具 | `pytest tests/unit/test_version_align.py tests/unit/test_object_info_merge.py` |

测试分层原则：
- 默认套件（unit + e2e）先跑绿，作为回归门禁。
- live 套件需真实 Modal 凭证和本地 ComfyUI 在线，产生真实费用（GPU 秒 + 卷流量）。
- 性能基线第一轮先测、先记录，第二轮与基线对比看回归。

- 单实例 SQLite 单进程：性能目标按单机单人使用场景定，不对标多用户生产部署。
- 性能基线第一轮测出后记入本文件第 8 节，第二轮对比回归。
- 性能测试用临时配置目录隔离，不污染真实用户配置。
