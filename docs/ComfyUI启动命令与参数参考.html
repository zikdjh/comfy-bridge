① 安装与启动方式

ComfyUI 是基于 Python 的 Stable Diffusion 节点式图形界面/WebUI。无论哪种安装方式，最终都是执行 python main.py [参数…] 启动，启动参数在各方式间通用。

方式一：源码安装（官方推荐，通用 Windows / Linux / macOS）

# 1. 创建虚拟环境（conda 示例，venv 亦可）
conda create -n comfyenv
conda activate comfyenv

# 2. 克隆仓库
git clone https://github.com/Comfy-Org/ComfyUI.git
cd ComfyUI

# 3. 安装 PyTorch（按显卡选其一）
# NVIDIA (CUDA 13.0)：
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130
# AMD (Linux, ROCm)：
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm7.2
# Apple Silicon (Mac)：
conda install pytorch-nightly::pytorch torchvision torchaudio -c pytorch-nightly

# 4. 安装 ComfyUI 依赖
pip install -r requirements.txt

# 5. 启动（默认监听 http://127.0.0.1:8188）
python main.py

Windows 下 AMD 显卡需 Windows 11 + 最新驱动 + 64 位 Python 3.13，PyTorch 使用 AMD 官方 ROCm 源；也可用 --directml 参数走 torch-directml。

方式二：Windows 便携整合包（ComfyUI Portable）

从 GitHub Releases 下载 ComfyUI_windows_portable_nvidia.7z（NVIDIA）或 ..._amd.7z（AMD），解压后双击 run_nvidia_gpu.bat / run_cpu.bat 启动。本质是调用内置 Python：

# bat 文件内部命令（可在命令行手动执行并追加任意参数）
.\python_embeded\python.exe -s ComfyUI\main.py --listen 0.0.0.0 --port 8188

更新：运行 update\update_comfyui.bat，或进入 ComfyUI 目录执行 git pull。

方式三：comfy-cli 命令行工具

pip install comfy-cli
comfy install                # 交互式安装（选择 GPU 类型、安装路径）
comfy launch                 # 前台启动
comfy launch -- --listen 0.0.0.0 --port 8188   # 传参给 ComfyUI（注意双横线 -- 分隔）
comfy launch --background -- --cpu             # 后台启动
comfy update                 # 更新

方式四：Comfy Desktop 桌面应用

官方桌面端（Windows 10+ / macOS 13+ / Linux .deb 或 AppImage），自动管理 Python 环境与多个实例，适合不熟悉命令行的用户。源码仓库：Comfy-Org/Comfy-Desktop。

② 启动命令基本语法与帮助

基本语法
python main.py [参数1] [参数2] …
查看帮助
python main.py -h 或 python main.py --help（列出当前版本全部参数，最权威）
默认地址
http://127.0.0.1:8188（默认仅本机可访问，端口 8188）
停止服务
在终端按 Ctrl + C，或直接关闭终端窗口
更新 ComfyUI
git pull && pip install -r requirements.txt（在安装目录内）
参数风格
长参数形如 --lowvram，短参数 -h；带值参数写法 --port 8188

③ 常用启动示例

网络 / 远程访问

python main.py                                  # 默认：仅本机 127.0.0.1:8188
python main.py --listen 0.0.0.0                 # 允许局域网访问（监听所有网卡）
python main.py --listen 0.0.0.0 --port 8189     # 自定义端口
python main.py --enable-cors-header "*"         # 允许跨域请求（前端开发/联调）
python main.py --tls-certfile cert.pem --tls-keyfile key.pem   # 启用 HTTPS
python main.py --auto-launch                    # 启动后自动打开浏览器

安全提醒：--listen 0.0.0.0 会将未加密的 Web 服务暴露给局域网，公网环境请配合 HTTPS、反向代理或防火墙使用。

显存 / 性能

python main.py --cpu                            # 纯 CPU 运行（无显卡/测试用）
python main.py --lowvram                        # 低显存优化（4GB 级显卡）
python main.py --novram                         # 几乎不占用显存
python main.py --highvram                       # 模型常驻显存，减少加载等待（大显存显卡）
python main.py --gpu-only                       # 所有内容全部保留在 GPU
python main.py --reserve-vram 2                 # 为系统/浏览器预留 2GB 显存，缓解爆显存
python main.py --fast                           # 启用全部实验性提速优化（可能影响画质）
python main.py --fast fp8_matrix_mult fp16_accumulation   # 仅启用指定优化

精度控制

python main.py --force-fp16                     # 强制 fp16（老卡提速）
python main.py --force-fp32                     # 强制 fp32（画质排障）
python main.py --fp8_e4m3fn-unet --fp8_e4m3fn-text-enc   # 模型与文本编码器用 fp8（省显存）

目录与模型路径

python main.py --output-directory D:\ComfyOut --input-directory D:\ComfyIn
python main.py --extra-model-paths-config extra_model_paths.yaml   # 复用 WebUI 等已有模型
python main.py --base-directory D:\ComfyData                      # 整体迁移数据目录

预览 / 缓存 / 调试

python main.py --preview-method auto            # 采样过程实时预览（latent2rgb 或 taesd）
python main.py --preview-method taesd --preview-size 768
python main.py --cache-none                     # 最小化缓存，排查节点缓存问题
python main.py --disable-all-custom-nodes       # 跳过全部自定义节点，排查启动报错
python main.py --disable-metadata               # 生成图片不写入提示词等元数据
python main.py --verbose DEBUG                  # 调试日志级别

④ 全部启动参数明细（可直接搜索）

以下参数整理自官方源码 comfy/cli_args.py（master 分支）。ComfyUI 迭代较快，请以 python main.py -h 输出为你所用版本的最准确列表。

服务与网络 Server

参数默认值说明
--listen [IP]127.0.0.1监听 IP，默认仅本机。不带值使用时监听 0.0.0.0,::（所有 IPv4/IPv6 网卡，即允许局域网访问）；支持逗号分隔多个地址，如 127.2.2.2,127.3.3.3
--port8188监听端口
--tls-keyfile <路径>无TLS 私钥文件路径，启用 HTTPS；必须与 --tls-certfile 同时设置
--tls-certfile <路径>无TLS 证书文件路径，启用 HTTPS；必须与 --tls-keyfile 同时设置
--enable-cors-header [来源]无允许指定来源的跨域请求；不带值时默认 *（允许所有来源）
--max-upload-size <MB>100最大上传文件大小（MB）
--auto-launch关闭启动后在默认浏览器自动打开界面
--disable-auto-launch关闭禁用浏览器自动打开（优先级高于 --auto-launch 与 Windows 整合包默认行为）

目录与路径 Directory

参数默认值说明
--base-directory <路径>无设置基础目录，models、custom_nodes、input、output、temp、user 均以此为根
--extra-model-paths-config <yaml>无加载一个或多个 extra_model_paths.yaml，挂载其他目录/其他软件的模型；可重复传参
--output-directory <路径>无输出（生成图片/视频）目录
--temp-directory <路径>无临时文件目录
--input-directory <路径>无输入文件目录
--user-directory <路径>无用户数据目录（配置、工作流等）
--models-directory <路径>无模型目录（覆盖默认 models 文件夹）

设备选择 Device

参数默认值说明
--cuda-device <ID>无本实例使用的 CUDA 设备，逗号分隔如 0 或 0,1；all 表示使用全部可见设备，其余设备将被隐藏（多卡分实例常用）
--default-device <ID>无仅设置默认设备，其他设备保持可见
--cuda-malloc启用使用 cudaMallocAsync（现行默认行为）
--disable-cuda-malloc关闭禁用 cudaMallocAsync（某些驱动/卡型崩溃时可尝试）

模型精度 Precision同组参数互斥

参数默认值说明
--force-fp32关闭强制以 fp32 运行（若效果更好请反馈官方）
--force-fp16关闭强制以 fp16 运行；会同时把 UNet 权重设为 fp16
--fp32-unet / --fp64-unet / --bf16-unet / --fp16-unet自动指定扩散模型（UNet）权重精度
--fp8_e4m3fn-unet / --fp8_e5m2-unet / --fp8_e8m0fnu-unet自动以 fp8 存储/运行扩散模型权重（省显存，e4m3fn 最常用）
--fp16-vae / --fp32-vae / --bf16-vae自动指定 VAE 精度；fp16 在部分 VAE 上可能输出黑图
--cpu-vae关闭VAE 在 CPU 上解码（显存不足导致解码爆显存时常用）
--fp8_e4m3fn-text-enc / --fp8_e5m2-text-enc / --fp16-text-enc / --fp32-text-enc / --bf16-text-enc自动指定文本编码器（CLIP/T5 等）权重精度
--fp16-intermediates关闭节点间传递的中间结果使用 fp16实验性
--force-channels-last关闭强制 channels-last 内存格式实验性，部分显卡（如 4090）可能更快

Intel / AMD(DirectML) Intel

参数默认值说明
--directml [设备号]无使用 torch-directml 后端（Windows 下 AMD/Intel 显卡的常用方案）
--oneapi-device-selector <选择器>无设置实例运行的 oneAPI 设备（Intel 显卡）
--supports-fp8-compute关闭让 ComfyUI 认为设备支持 fp8 计算，文本编码器改用 fp8 算子
--enable-triton-backend / --disable-triton-backend关闭启用/禁用 comfy-kitchen Triton 编译后端

注意力机制 Attention前 6 项互斥

参数默认值说明
--use-split-cross-attention关闭分片交叉注意力（部分老卡更省显存）
--use-quad-cross-attention关闭quad 交叉注意力实现
--use-pytorch-cross-attention关闭使用 PyTorch 原生 scaled_dot_product_attention（新卡默认首选）
--use-sage-attention关闭使用 SageAttention（需额外安装 sageattention 库，提速明显）
--use-flash-attention关闭使用 FlashAttention
--use-ck-attention关闭使用 comfy-kitchen 注意力实现
--disable-xformers关闭禁用 xformers（未安装或排障时）
--force-upcast-attention / --dont-upcast-attention自动强制/禁止注意力上浮精度（黑图、花图排障用）

采样预览 Preview

参数默认值说明
--preview-method [方法]none采样节点进度预览方法，可选 none（不预览）/ auto（自动，装了 TAESD 用 TAESD）/ latent2rgb（速度快、偏色）/ taesd（质量好，需下载 TAESD 模型）
--preview-size <px>512预览图最大边长（像素）

节点缓存 Cache

参数默认值说明
--cache-ram [GB [GB]]按内存自动RAM 压力缓存（当前默认缓存模式）：第 1 个值为"活动缓存"阈值，第 2 个值为"非活动缓存/固定"阈值；不传值时默认活动阈值=内存的 10%（2–10GB），非活动阈值=内存的 100%（上限 128GB）
--cache-classic关闭使用旧版激进缓存策略
--cache-lru N0LRU 缓存最近 N 个节点结果（更吃内存/显存）
--cache-none关闭最小化缓存，节点每次都重新执行（排障用）
--high-ram关闭针对大内存机器的优化，等价于启用旧版激进缓存

显存与内存管理 VRAM前 6 项互斥

参数默认值说明
--gpu-only关闭所有内容（含文本编码器/CLIP）全部保留在 GPU
--highvram自动检测模型用完不卸载、常驻显存，省去反复加载时间（大显存推荐）
--normalvram自动检测强制正常显存策略（当系统自动进入 lowvram 但实际显存够用时使用）
--lowvram自动检测低显存优化：UNet 分块加载，速度换可用性（4–6GB 显卡）
--novram自动检测几乎不把模型加载进显存（极低显存）
--cpu关闭全部（含文本编码器/VAE/扩散模型）用 CPU 运行
--reserve-vram <GB>按系统自动为操作系统/其他软件预留指定 GB 显存
--vram-headroom <GB>0DynamicVRAM 额外保留的空闲显存（连其他程序占用也一并计入）
--disable-nvml-pressure关闭用 CUDA 而非 NVML 检测显存压力（NVML 读数异常时）
--async-offload [流数]关闭权重异步卸载，可指定 CUDA 流数量
--disable-async-offload关闭禁用异步卸载
--enable-dynamic-vram / --disable-dynamic-vram自动开/关 DynamicVRAM 动态显存调度
--fast-disk / --disable-fast-disk自动允许/禁止用磁盘作为动态加载缓存（SSD 才建议开启）
--disable-smart-memory关闭更激进地把模型卸载回内存释放显存
--disable-pinned-memory关闭禁用锁页内存（内存不足时）
--mmap-torch-files关闭加载 .ckpt/.pt 文件时使用内存映射
--disable-mmap关闭加载 safetensors 时不使用 mmap（Windows 内存占用异常时可尝试）

性能优化与编译 Performance

参数默认值说明
--fast [特性…]关闭启用实验性优化，可选值：fp16_accumulation、fp8_matrix_mult、cublas_ops、autotune；不带值=全部启用；可能轻微影响画质甚至崩溃实验性
--disable-cuda-graphs关闭禁用 CUDA Graphs（部分驱动/卡型不兼容时）
--disable-comfy-compiler关闭禁用模型编译器（同时禁用 CUDA Graphs）
--assert-graph-breaks关闭编译器遇到图断点时报错中断（开发调试）
--force-non-blocking关闭强制张量操作使用非阻塞模式
--default-hashing-function <算法>sha256模型去重比对哈希算法，可选 md5 / sha1 / sha256 / sha512
--deterministic关闭启用确定性 PyTorch 算法（结果可复现，速度变慢）
--debug-hang关闭程序卡死时按 Ctrl-C 输出全部堆栈

ComfyUI-Manager Manager

参数默认值说明
--enable-manager关闭启用内置 ComfyUI-Manager（安装/管理自定义节点）
--disable-manager-ui / --enable-manager-legacy-ui关闭禁用 Manager 界面 / 启用旧版界面（后者会隐含启用 Manager）

自定义节点 Custom Nodes

参数默认值说明

--whitelist-custom-nodes <目录…>空即使禁用了自定义节点，也仍然加载指定目录
--disable-api-nodes关闭禁用 API 节点及前端的外网访问（离线环境）
--multi-user关闭启用多用户模式（按用户隔离存储）

日志与杂项 Logging / Misc

参数默认值说明
--dont-print-server关闭不在控制台打印请求日志
--verbose [级别 [文件]]空设置控制台日志级别（如 DEBUG），或以 级别 文件名 同时输出到文件；可重复传参
--log-stdout关闭日志输出到 stdout 而非默认的 stderr
--quick-test-for-ci关闭CI 快速自检模式（起服务即退出验证）
--windows-standalone-build关闭标记为 Windows 独立整合包（隐含启用自动打开浏览器）

前端版本 Frontend

--front-end-root <目录>无使用本地前端目录（优先于版本号，前端开发用）

⑤ 额外模型路径配置 extra_model_paths.yaml

把仓库自带的 extra_model_paths.yaml.example 复制为 extra_model_paths.yaml 放到 main.py 旁（或用 --extra-model-paths-config 指定路径），即可复用其他目录（如 WebUI 整合包）的模型，避免重复下载：

comfyui:
    base_path: /path/to/comfyui/          # 基础路径
    is_default: true
    checkpoints: models/checkpoints/
    loras: models/loras/

a111:                                     # 复用 Stable Diffusion WebUI (A1111) 的模型
    base_path: /path/to/stable-diffusion-webui/
    checkpoints: models/Stable-diffusion
    configs: models/Stable-diffusion
    vae: models/VAE
    loras: models/Lora
    upscale_models: models/ESRGAN
    embeddings: embeddings
    hypernetworks: models/hypernetworks
    controlnet: models/ControlNet

⑥ 使用提示

  • 参数互斥：显存模式（--gpu-only / --highvram / --normalvram / --lowvram / --novram / --cpu）、注意力实现、各精度组均为互斥组，同组只生效最后一个或直接报错，不要同时传。
  • 显存策略：现代显卡一般交给 ComfyUI 自动检测即可；爆显存先试 --reserve-vram 1~2，再考虑 --lowvram；VAE 解码爆显存可加 --cpu-vae。
  • 排查问题三板斧：--disable-all-custom-nodes（排除节点冲突）→ --cache-none（排除缓存）→ --verbose DEBUG（看详细日志）。
  • 远程访问安全：--listen 0.0.0.0 后任何人都能访问该服务，建议加上 --tls-*、置于反向代理之后，或仅在内网使用。
  • comfy-cli 传参：必须用双横线 -- 分隔，如 comfy launch -- --listen 0.0.0.0。
  • 版本差异：参数随版本快速演进（如缓存模式、DynamicVRAM 等为较新特性），本文以 master 分支为准；旧版本请以 python main.py -h 输出为准。
