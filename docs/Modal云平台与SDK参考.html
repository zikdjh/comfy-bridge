① 平台概述

Modal（Modal Labs 出品，modal.com）是一个面向 AI / 数据工作负载的 Serverless 云计算平台：开发者只写普通 Python 代码，通过装饰器声明资源（GPU、镜像、存储、并发等），代码即可在云端容器中运行并自动伸缩——无需管理 Kubernetes、Docker 或云厂商账号。

核心特性

Serverless GPU / CPU
按秒计费、无闲置费用；跨云（AWS / GCP / OCI 等）资源池化，自动选择运行位置
一切皆代码
容器环境（Image）、GPU 规格、存储挂载、调度全部用 Python 声明，无需 YAML
自动伸缩
按需扩缩容器（0 → N → 0），支持预热（min_containers）、并发复用（modal.concurrent）
典型用途
模型推理服务、微调/批处理训练、AI Agent 代码执行沙箱（Sandboxes）、定时任务、数据管道
周边产品
Modal Notebooks（在线 Jupyter，闲置自动关机）、GPU Pods / Spot Pods（常驻 GPU 机器）、LLM 推理端点
官方 SDK
Python（主力，功能最全）、TypeScript / JavaScript（Beta）、Go（Beta）

② 核心概念与工作流

概念速览

App
应用的容器/命名单元，聚合 Function、Image 等资源：app = modal.App("my-app")
Function
用 @app.function() 装饰的函数，是云端执行的基本单元，可声明 GPU、内存、超时等
Image
容器镜像（环境）定义，链式构建：modal.Image.debian_slim().uv_pip_install(...)，按层缓存
Volume
分布式文件存储，跨容器共享持久数据（模型权重、数据集）
Secret
密钥管理，以环境变量注入容器（API Key、HuggingFace token 等）
Queue / Dict
云端消息队列 / 分布式字典，用于任务分发与共享状态
Sandbox
安全隔离的代码执行环境（可扩展到数千个），AI Agent 跑生成代码的主流方案
Web Endpoint
把函数/Web 服务暴露为 HTTPS URL（自动伸缩的 HTTP 服务）
Cls
@app.cls() 把类作为有状态的云端服务（常用于加载一次模型的推理类）

最小示例（官方文档原文）

import modal

app = modal.App("example-inference")
image = modal.Image.debian_slim().uv_pip_install("transformers[torch]")

@app.function(gpu="h100", image=image)
def chat(prompt: str | None = None) -> list[dict]:
    from transformers import pipeline      # 重依赖在函数内导入，加快冷启动
    chatbot = pipeline(model="Qwen/Qwen3-1.7B", device_map="cuda", max_new_tokens=1024)
    ...
    return result

@app.local_entrypoint()                    # 本地入口：modal run xxx.py 时执行
def main():
    print(chat.remote("你好"))             # .remote() 在云端容器中执行
modal run chat.py        # 临时运行一次：本地触发、云端执行，跑完即退
modal deploy chat.py     # 常驻部署：生成稳定的 Web 端点/定时任务，按用量计费
modal serve chat.py      # 开发模式：代码热重载的 Web 端点

modal run 适合一次性任务与调试；modal deploy 后应用常驻 Modal 平台（Web 端点、定时调度生效），有请求才启动容器、按秒计费。

GPU 类型与多卡写法 GPU

gpu 取值显存 / 上限说明
"T4" / "L4" / "A10" / "L40S"最多 8 卡（A10 最多 4 卡）入门/推理性价比档，官方建议推理从 L40S（48GB）起步
"A100" / "A100-40GB" / "A100-80GB"最多 8 卡裸 "A100" 可能自动升级为 80GB 版
"H100" / "H100!"80GB，最多 8 卡可能自动升级到 H200（价格不变）；加 ! 禁止升级
"H200" / "B200" / "B200+" / "B300"最多 8 卡（最高 2304GB）Blackwell 代：B300 需 CUDA 13.1+；B200+ 可能分配到 B300 但按 B200 计费
"RTX-PRO-6000"最多 8 卡RTX PRO 6000 Blackwell 工作站卡
"H100:8" 写法类型:数量多卡同机：@app.function(gpu="H100:8")；同一函数内所有 GPU 在同一物理机
回退列表list[str]按顺序优先分配：gpu=["H100", "A100-40GB:2"]

多节点（跨机）分布式训练目前为私测，需联系 support@modal.com；单机多卡已支持。

Image 镜像构建方法 Image

方法说明
modal.Image.debian_slim(python_version="3.13")默认基础镜像：精简 Debian，Python 版本默认与本地一致
.uv_pip_install(...) / .pip_install(...)安装 Python 包（推荐 uv，可固定版本如 "torch==2.8.0"）
.apt_install("git", "curl")安装系统包
.env({"PORT": "6443"})设置环境变量（名称与值须为字符串）
.run_commands("git clone …")执行任意 shell 命令作为构建层
.run_function(download_models, gpu=..., secrets=[...], volumes={...})在构建期执行 Python 函数（如预下载模型），可接受 function 的大部分参数
.add_local_dir(...) / .add_local_file(...) / .add_local_python_source("模块名")挂载/打包本地文件与 Python 模块；默认启动时挂载不新建层（重部署快），copy=True 强制烧进镜像
modal.Image.micromamba().micromamba_install("pymc==5.10.4", channels=["conda-forge"])需要系统包 + Python 包混合安装时用 conda 系
modal.Image.from_registry("repo/image:tag")复用 Docker Hub 等现有镜像（也可基于自定义 Dockerfile）
with image.imports():声明全局作用域导入（配合内存快照优化冷启动）
 
image = (
    modal.Image.debian_slim(python_version="3.13")
    .apt_install("git")
    .uv_pip_install("torch==2.8.0")
    .env({"HALT_AND_CATCH_FIRE": "0"})
    .run_commands("git clone https://github.com/modal-labs/agi && echo 'ready to go!'")
)

镜像按层缓存，常变层放最后；force_build=True 强制单层重建，MODAL_IGNORE_CACHE=1 从头重建且不破坏缓存。

定时任务 Schedule

方式说明
schedule=modal.Period(hours=5)固定间隔触发；重新部署会重置计时
schedule=modal.Cron("0 8 * * 1", timezone="Asia/Shanghai")cron 语法按固定时刻触发，不受重新部署影响；默认 UTC，可指定时区
 
@app.function(schedule=modal.Cron("0 6 * * *", timezone="America/New_York"))
def daily_job(): ...

# 定时任务需部署后生效：
modal deploy daily_job.py

Web 端点 Web Endpoints

装饰器适用场景与说明
@modal.fastapi_endpoint()一行把普通 Python 函数变 Web 端点（内部包成 FastAPI）；支持 GET 查询参数 / POST JSON（method="POST"）
@modal.asgi_app()函数返回 ASGI 应用（FastAPI、Starlette、FastHTML 等）
@modal.wsgi_app()函数返回 WSGI 应用（Flask、Django 等）
@modal.web_server(8000)暴露任意非 ASGI/WSGI 服务器（aiohttp、tornado、http.server 等）：请求转发到容器内该端口，服务器须绑定 0.0.0.0
 
@app.function(image=image)
@modal.fastapi_endpoint()
def square(x: int):
    return {"square": x ** 2}
# 部署后 URL 形如：https://<工作区>--<应用名>-<函数名>.modal.run

要点：请求体上限 4 GiB；支持 WebSocket；常搭配 @modal.concurrent(max_inputs=100) 提升单容器并发；新账户限速 200 请求/秒；可用 Modal-Key/Modal-Secret 请求头做代理认证。

存储与密钥 Volume / Secret

volume = modal.Volume.from_name("my-data", create_if_missing=True)
secret = modal.Secret.from_name("huggingface-secret")   # 在 Dashboard 或 CLI 创建
hf_cache = modal.Volume.from_name("huggingface-cache", create_if_missing=True)

@app.function(gpu="A100", volumes={"/data": volume, "/root/.cache/huggingface": hf_cache},
              secrets=[secret])
def train(): ...

Volume 用于模型权重/数据集共享与持久化；另有 modal.CloudBucketMount 直接挂载 S3/GCS 桶、modal.NetworkFileSystem 旧式网络文件系统、modal.Dict/modal.Queue 云端键值与队列。

⑤ TypeScript / JavaScript 与 Go SDK（均为 Beta）

TypeScript / JavaScript SDK

npm install modal        # 要求 Node 22+；也支持 Deno / Bun；附完整 TS 类型
import { ModalClient } from "modal";

const modal = new ModalClient();
const app = await modal.apps.fromName("sandbox-app", { createIfMissing: true });
const image = modal.images.fromRegistry("alpine:3.21");
const sb = await modal.sandboxes.create(app, image, { command: ["cat"] });

// 调用已部署的函数（Python 定义）
const echo = await modal.functions.fromName("my-app", "echo");
const ret = await echo.remote(["Hello, Modal!"]);

限制：Python 仍是唯一的 Function 运行时——JS SDK 只能查找并调用已部署函数、创建 Sandbox 等，不能定义 Function；批量调用暂不支持。认证优先级：客户端参数 > MODAL_TOKEN_ID/MODAL_TOKEN_SECRET 环境变量 > ~/.modal.toml。处于 0.X Beta 阶段，可能含破坏性变更。

go get github.com/modal-labs/modal-client/go@latest   # 要求 Go 1.25.0+
mc, err := modal.NewClient()

defer mc.Close()

⑦ 使用提示

  • 冷启动优化：函数内导入重依赖 + with image.imports()；预热 min_containers=1；延长 scaledown_window；开 enable_memory_snapshot=True。
  • 推理选卡：官方建议从 L40S（48GB）起步，性价比高；大模型再上 H100/H200/B200。
  • GPU 自动升级：H100 可能被升级为 H200（同价），A100 可能升级 80GB；要锁定写 H100!。
  • run vs deploy：调试用 modal run，上线用 modal deploy；Period 定时任务重部署会重置计时，要固定时刻用 Cron。
  • 状态复用：模型加载等重初始化放 @app.cls() 的 @modal.enter() 中，配合 @modal.concurrent() 单容器多并发，避免每次请求都加载模型。
  • 本地目录：本地 Python 模块用 add_local_python_source 打包；add_local_* 默认启动时挂载而非烧进镜像，重部署更快。
  • 镜像缓存：按层缓存且级联失效，常变层放最后；构建慢时用 MODAL_IGNORE_CACHE=1 排查。
  • 非 Python 客户端：JS/Go SDK 只能调用已部署的 Python 函数和管理 Sandbox，定义 Function 仍需 Python。
