八、遗留与建议

  • 节点选型写入运维文档：krea2 架构 GGUF 须用 calcuis/gguf 的 LoaderGGUF；city96 版适用于其支持列表内架构（flux/sdxl 等）。
  • 启动脚本健壮性：dev.ps1 可加入 node PATH 探测/注入，或在安装文档中注明 Node ≥ 18 且需在 PATH。
  • 限流退避（已闭环）：1e6881d 已为 Modal 控制面只读命令增加 1s/4s/10s 多级退避重试，降低启动期首检失败概率。
  • 镜像固化（可选优化）：calcuis/gguf 自带连接器无需 pip 依赖，暂无需重建镜像；后续引入带 requirements 的节点时经「镜像重建」烧进镜像层。
  • 本轮未覆盖（依赖真实费用或并发场景）：预热确定执行的真实冷启动计费验证、多任务并发排队、大分辨率上云阈值触发、隐私确认首次弹窗（本轮带头直通）、跨站 Origin 403 与管理令牌鉴权（回环部署无令牌）。
  • 收尾状态：测试结束后本地 ComfyUI 经桥接器 API 停止、桥接器与前端关闭，三端口验证离线；Modal 应用无常驻容器，闲置自动缩容到零。
