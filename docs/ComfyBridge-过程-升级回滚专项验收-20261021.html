ComfyBridge 升级与回滚专项验收

适用：v0.1.0-beta.8 及后续整合包 · 可靠性 R3

执行原则：保留旧版目录；使用隔离配置或真实用户数据副本；不触发真实 Modal 生图。

1. 验收目标与边界

本专项验证整合包从旧版目录切换到新版目录时的版本识别、升级前自动备份、启动自检、数据恢复以及程序回退顺序。验收对象是桌面整合包与本地管理台，不验证打包产物内部依赖是否齐全，也不执行真实 Modal 出图、卷写入或本地生图。

  • 用户数据根：~/.comfybridge；程序根为两个独立解压目录。
  • 备份边界：备份包含 Modal 凭证和上传会话元数据，下载需要管理面认证。
  • 回滚边界：程序回退通过重新打开旧版目录完成；数据回退通过版本迁移备份和下一次启动恢复完成。

6. 失败判定与收口

  • P0：升级备份包含明文凭证泄露；未备份就迁移数据库；恢复覆盖错误文件；新版失败后旧版无法启动；数据丢失或静默污染。
  • P1：版本卡片显示错误；升级历史重复；恢复需要重启但没有明确提示；新进程残留导致旧版端口冲突。
  • P2：时间格式、空态、按钮文案或表格换行问题，不影响数据边界。

任一 P0 或 P1 未关闭，不满足 R3 正式发布条件。P2 可带问题放行，但需登记到修复清单并在下一测试版回归。
